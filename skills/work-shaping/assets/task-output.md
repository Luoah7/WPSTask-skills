# 工作成型输出模板

```text
标题：
目标：                           [原文|推断|〔需确认〕]
主责人：                         [原文|推断|〔需确认〕]
交付物：                         [原文|推断|〔需确认〕]
完成标准：                       [原文|推断|〔需确认〕]
截止时间：                       [原文|推断|〔需确认〕]
范围边界：                       仅在原文存在歧义时输出
已知风险：                       仅在原文提到时输出
```

多条任务使用清晰分隔，每条保持相同字段顺序。结尾说明还缺什么，并给出基于真实缺口的下一步。
